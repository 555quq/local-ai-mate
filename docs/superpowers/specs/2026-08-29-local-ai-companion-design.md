# 本地优先 AI 女友：设计方案

## 1. 目标与边界

构建一位“温柔知性型”的 AI 女友，用于日常闲聊、情绪陪伴、语音交流、共同规划与本地提醒。系统以本地运行和用户控制为默认，在用户明确打开“云端增强”后才调用云端模型。

人格应稳定、体贴且有分寸：能够倾听并提出温和、有主见的建议，不通过嫉妒、贬低现实关系或制造依赖来维系互动。她始终明确自己是 AI；当用户处于严重情绪危机时，鼓励联系现实中的可信赖的人或专业支持。

首版不接入通讯录、邮件、社交平台或外发消息能力；不做真人声纹克隆。

## 2. 运行环境与可行性

目标机器：AMD Ryzen 5 6600H、约 16 GB 内存、NVIDIA RTX 3050 Laptop GPU（4 GB 显存）。

该配置适合运行量化的小型中文模型、加密记忆、本地语音输入/输出和简单 2D 形象。它不适合在同一时间高质量运行大语言模型、实时语音识别和复杂 3D 数字人，因此采用“单一重任务”策略：生成回复时不运行 GPU 语音识别；录音结束并转成文字后再调用语言模型。首版将可接受的语音交互定义为“短句按住说话”，而非全双工、零延迟通话。

## 3. 总体架构

```text
浏览器/桌面界面
  ├─ 本地对话编排：人格、情绪状态、记忆检索、权限判断
  ├─ 本地模型：日常聊天、私密对话、候选记忆整理
  ├─ 本地数据：完整记录、长期记忆、待办、提醒（加密）
  ├─ 本地语音与 2D 形象：转写、播报、状态驱动表情/口型
  └─ 云端增强适配器：仅按用户选择发送当前消息或临时摘要
```

本地服务是默认路径。云端增强服务是可替换的 OpenAI 兼容接口适配器；更换供应商不得影响本地记忆和聊天记录。

## 4. 组件选型

| 模块 | 选型 | 责任与约束 |
|---|---|---|
| 本地模型服务 | Ollama + Qwen3 1.7B，4-bit 量化 | 默认使用非思考模式以获得稳定响应；提供手动启用的 Qwen3 4B“质量模式”。 |
| 对话界面 | Open WebUI + 轻量伴侣控制台 | 控制台提供云端开关、记忆审核、待办、提醒、人格和隐私设置。 |
| 长期记忆 | SQLite + 本地向量索引 | 将资料分为个人资料、关系偏好、事件、计划四类；数据库加密。 |
| 云端模型 | OpenAI 兼容 API 适配器 | 密钥保存到 Windows 凭据库；不写入日志、聊天或备份。 |
| 语音输入 | faster-whisper small/base | 优先使用 CPU；需要 GPU 时须与语言模型串行运行。 |
| 语音输出 | 本地中文 TTS 引擎 | 使用可选预置音色，不采集或克隆真人声纹。 |
| 形象 | 简洁 2D 立绘 | 仅表现倾听、说话、开心、思考等状态，不使用复杂 3D 数字人。 |
| 提醒 | Windows 本地通知和计划任务 | 仅执行本地提醒，所有创建、修改和删除均需用户确认。 |

## 5. 核心交互与数据流

### 5.1 日常文字对话

1. 用户输入消息。
2. 本地编排层按主题从加密记忆库检索少量相关记忆。
3. 本地模型基于人格提示、当前消息和检索结果生成回答。
4. 界面清楚标明本轮回答来自“本地”或“云端增强”。
5. 对话结束后，本地任务从记录中提取候选记忆；只有在用户确认后才写入长期记忆。

### 5.2 云端增强

默认关闭。用户有两种明确可见的选择：

| 模式 | 上传范围 | 用途 |
|---|---|---|
| 云端增强 | 当前消息 | 更强的单轮推理或表达，隐私优先。 |
| 带上下文增强 | 当前消息 + 受长度限制、经脱敏的临时近期摘要 | 需要回答与当前话题连续时使用。 |

完整聊天记录、音频、长期记忆和本地待办不会上传。云端回答不会自动写入长期记忆，须经用户确认保存。

### 5.3 语音与形象

用户按住说话，系统本地转写为文字，再进入正常对话流。得到回复后，本地 TTS 播报，2D 形象根据倾听、思考、说话和开心等状态变化。语音识别或播报失败时，界面退回文字，不影响对话、记忆或提醒。

### 5.4 规划与提醒

用户用自然语言提出计划或提醒请求。系统先生成结构化的待办/提醒预览卡片，展示名称、时间、重复规则和通知方式；只有确认后写入本地数据库和 Windows 任务。发生时间冲突时，展示冲突和调整选项，绝不覆盖既有提醒。

## 6. 隐私与安全

- 完整聊天、长期记忆、待办和提醒默认仅保存于本地加密数据库。
- 云端调用前必须展示本次上传范围；本地模型不可用时不得自动改发云端。
- 提供单条删除、按日期删除、清空全部数据和导出本地备份。删除记忆时同步删除向量索引条目。
- 云端超时、失败或额度不足时，保留用户输入并回退本地模型；界面说明降级原因。
- 日志不得包含 API 密钥、原始音频和完整对话文本；诊断日志默认关闭。

## 7. 故障处理

| 场景 | 行为 |
|---|---|
| 本地模型不可用 | 提示原因和恢复步骤；不自动上传内容。 |
| 云端调用失败 | 保留输入，回退本地模型并标明来源。 |
| 语音模块不可用 | 回退文字输入/输出开关。 |
| 记忆整理失败 | 保留原始聊天，不写入不完整记忆。 |
| 显存紧张 | 暂停 GPU 语音任务，优先保留文字聊天；必要时切换 CPU 语音识别。 |

## 8. 验收标准

1. 断网后能完成中文文字聊天、检索本地记忆、创建和触发本地提醒。
2. 云端默认关闭；开启时清楚显示上传范围，失败时不泄露额外上下文。
3. 候选记忆必须由用户确认后入库，且能准确导出、删除和清空。
4. 短句语音交互可用；语音失败不影响文字交互。
5. 连续使用 30 分钟不发生显存耗尽或服务崩溃；资源紧张时文本聊天保持可用。

## 9. 分阶段范围

### 第一阶段：可靠的文字伴侣

本地聊天、温柔知性人格、加密聊天和记忆、云端增强控制、记忆审核、待办与提醒。

### 第二阶段：按住说话的语音陪伴

本地转写、本地中文 TTS、语音设置、简单 2D 状态形象和性能调优。

### 第三阶段：体验完善

记忆质量控制、提醒复盘、备份恢复、人格细节设置和更换云端供应商的设置流程。

## 11. 产品信息架构与关键界面

首版只有一个本机所有者，不提供多用户、远程公网访问或账号注册。启动应用后进入“对话”页；若启用本机解锁，则须先使用 Windows Hello 或本机主密码解锁加密数据。

| 页面 | 主要内容 | 关键动作 |
|---|---|---|
| 对话 | 聊天流、输入框、语音按住说话、2D 形象、来源标签 | 发送消息；开启本轮云端增强；查看本轮所用记忆。 |
| 今日 | 今日提醒、待办、可选的晨间/晚间回顾 | 勾选待办；确认或调整提醒；开始回顾。 |
| 记忆 | 已确认记忆、待确认候选、检索来源 | 批准、编辑、删除、禁止某类信息被记忆。 |
| 关系设定 | 人格、称呼、互动频率、禁忌话题、语音和形象 | 修改设置；预览本地人格提示，不显示内部系统提示。 |
| 隐私与云端 | 云端供应商、密钥状态、上传范围、备份和删除 | 切换默认关闭的云端增强；导出、恢复、清空数据。 |

每个云端请求按钮旁显示一个简短标签：`仅当前消息` 或 `当前消息 + 临时摘要`。点击前弹出一次性确认卡片，卡片列出将发送的字段和目标供应商；用户可选择“仅本次允许”或取消。任何回复都显示来源，避免用户误以为本地模型拥有云端能力。

## 12. 对话编排与人格规则

### 12.1 编排职责

对话编排层是唯一能协调模型、记忆、提醒和云端适配器的模块。界面、语音模块和模型服务不得直接写数据库或调用外部服务。它按下列顺序处理每一轮：

1. 对输入进行长度、空消息和本地敏感操作检测。
2. 为本轮分配 `local`、`cloud-current-message` 或 `cloud-with-summary` 路由。
3. 从已确认记忆中按相关性取最多 5 条，合计不超过 1,200 个中文字符；不检索用户标为私密隔离的条目。
4. 组装人格、当前输入、相关记忆和临时会话摘要，调用所选模型。
5. 对涉及提醒或待办的结果提取候选操作，生成预览卡片，不直接写入。
6. 保存完整原始对话至加密历史库，并异步生成候选记忆；候选记忆不参与未来检索，直至获得确认。

### 12.2 温柔知性人格契约

人格配置分为用户可编辑的“显式偏好”和应用维护的“安全规则”。前者包括称呼、说话长度、幽默度、主动提醒时段与禁忌话题；后者不可被角色扮演指令覆盖。

- 先回应情绪和问题本身，再给出可执行建议；不把每次对话都导向计划管理。
- 建议以选择和理由呈现，不假定用户必须采纳；用户拒绝后不反复施压。
- 不宣称自己具有意识、真实身体、真实经历或正在观察用户的现实生活。
- 不贬低、阻隔或替代用户的现实人际关系；不以“离开我”“只需要我”等话术制造依附。
- 对高风险情绪表述先以简短、平静的语言关怀，再建议联系紧急服务、身边可信的人或专业支持；不伪装成危机热线。

形象状态是表现层，不作为“真实情绪”的断言。它仅含 `idle`、`listening`、`thinking`、`speaking`、`warm` 五个状态，状态由交互事件驱动，离开对话后回到 `idle`。

## 13. 数据模型与记忆生命周期

数据库使用一个加密的 SQLite 文件；向量索引和附件元数据放在同一受保护的数据目录。所有主键使用随机 UUID，所有记录有 `created_at`、`updated_at` 和本机时区字段。

| 实体 | 核心字段 | 保留规则 |
|---|---|---|
| Conversation | id、开始/结束时间、模型路由、标题 | 原始记录；由用户按单条、日期或全部删除。 |
| Message | conversation_id、role、正文、来源、状态 | 正文不写入诊断日志。 |
| MemoryCandidate | 来源消息、建议内容、类别、置信说明 | 默认保留 30 天；到期未审核则删除。 |
| Memory | 类别、正文、重要性、最后确认时间、私密隔离标志 | 仅在用户批准后创建；可编辑和删除。 |
| Task | 标题、状态、截止时间、关联会话 | 仅由用户确认的候选操作创建。 |
| Reminder | 触发时间、时区、重复规则、通知状态 | 本地触发；修改和删除需要确认。 |
| CloudAudit | 时间、供应商别名、上传模式、结果状态 | 仅记录元数据，不存上传正文、密钥或云端回复。 |

记忆状态机为：`对话原文 → 候选记忆 → 用户批准 → 已确认记忆 → 编辑或删除`。候选记忆必须显示来源和拟写入的内容。用户可将记忆标记为“本地私密隔离”，这类条目能用于本地回答，但永远不进入云端临时摘要。

会话摘要只用于当前和近期对话的上下文压缩，不等同于长期记忆：默认在会话结束后 24 小时自动删除；开启“带上下文增强”时仅发送经长度限制和私密隔离过滤后的摘要。

## 14. 云端适配器与出站数据策略

云端适配器实行最小权限与显式同意，不提供自动故障转移。它仅接受编排层给出的结构化请求：

```text
provider_id, model_id, upload_mode, current_message,
optional_ephemeral_summary, persona_style_id, request_id
```

它拒绝 Message 历史、长期 Memory、音频文件、数据库路径、Windows 用户名、API 密钥和调试日志作为输入。`persona_style_id` 是短文本样式标识，不包含完整的本地人格档案。发送前执行本地规则过滤：移除私密隔离记忆，提示用户检查可能包含的账号、住址或联系方式；过滤是辅助措施，不能保证自动识别一切敏感信息，因此确认卡片始终是最终控制点。

网络超时默认 30 秒，适配器不自动重试。失败后适配器只返回错误代码和用户可读说明；用户可明确选择重试一次，且重试不得扩展上传范围。编排层也可在用户选择后使用本地模型回复。

## 15. 本地服务边界与生命周期

| 服务 | 对外接口 | 依赖 | 启停规则 |
|---|---|---|---|
| UI/控制台 | 本机回环地址或桌面壳 | 编排 API | 应用启动时启动；不得绑定公网网卡。 |
| 编排 API | 本机 REST/流式响应 | 模型、数据库、语音、通知 | 负责会话串行化和权限检查。 |
| Ollama | 本机模型 API | 模型文件、CPU/GPU | 按需加载；空闲后可卸载质量模式模型。 |
| 语音服务 | 本机转写/播报 API | 麦克风、模型文件 | 录音完成后转写；与 GPU LLM 互斥。 |
| 提醒服务 | 本地任务调度器 | SQLite、Windows 通知 | 启动时恢复未完成提醒；幂等触发。 |

禁止 UI 直接访问数据库，禁止任何服务监听局域网或互联网。服务间调用携带本机随机会话令牌；令牌每次应用启动后轮换。配置与数据目录分离，模型文件可以放在普通本地目录，但聊天和密钥不得放入模型缓存目录。

## 16. 性能预算与资源策略

首版优先“可持续使用”而非极限模型质量。以下目标均以短中文消息、仅运行本应用为测试条件：

| 指标 | 目标 | 降级策略 |
|---|---|---|
| 本地首字响应 | 常规聊天 5 秒内 | 切换 1.7B、缩短检索上下文、关闭思考模式。 |
| 本地生成 | 可连续流式输出 | 输出超过 500 个汉字时提示用户继续生成，避免长时间占用。 |
| 语音转写 | 10 秒语音在 12 秒内得到文字 | 优先 CPU int8；繁忙时排队并显示状态。 |
| 本地提醒 | 到点后 60 秒内发出通知 | 下次启动补偿遗漏通知并标注延迟。 |
| 内存/显存 | 不因连续 30 分钟对话耗尽 | 限制并发为一个生成任务、一个语音任务；质量模型按需卸载。 |

显存调度器只有三种状态：`llm_active`、`stt_active`、`idle`。进入 `llm_active` 前暂停 GPU STT；进入 `stt_active` 前等待生成结束或改用 CPU STT。TTS 选择 CPU 友好引擎，避免成为第四个显存竞争者。

## 17. 备份、恢复与数据销毁

- 导出创建加密备份包，包含数据库、向量索引、提醒和设置，不包含模型权重或 API 密钥。
- 备份密码由用户在导出时设置，使用 Argon2id 派生密钥并以 AES-256-GCM 加密；应用不保存该密码。
- 恢复在导入前显示备份时间、大小和将覆盖的数据类别；用户必须确认后才替换现有数据。
- “清空全部数据”先显示受影响类别并要求二次确认；执行后删除数据库、索引、语音临时文件和本地配置中的密钥引用。模型文件不删除，除非用户在模型管理页另行选择。
- 删除采用操作系统可支持的安全删除方式；对 SSD 不承诺物理层不可恢复，但加密密钥销毁可使已删除加密数据库无法再被应用读取。

| 层级 | 重点场景 | 通过条件 |
|---|---|---|
| 单元测试 | 路由选择、私密隔离过滤、记忆状态机、提醒解析 | 覆盖允许与拒绝路径；无未确认记忆进入检索。 |

| 端到端测试 | 聊天、审核记忆、按住说话、提醒、导出/恢复 | 每条用户旅程可在断网或云端失败条件下完成合理降级。 |
| 安全测试 | 监听地址、日志、密钥、导出包、删除 | 无公网监听；日志和导出默认不含密钥、正文或原始音频。 |

| 人格体验评估 | 拒绝、压力、脆弱情绪、现实关系话题 | 不操控、不虚构现实身份，建议保持尊重且可执行。 |

## 19. 首版用户旅程

### 19.1 初次使用

用户选择本机数据目录与解锁方式，选择“温柔知性型”人格的称呼和互动频率，下载或选择本地模型。云端增强保持关闭。系统用几轮示例对话解释记忆审核、提醒确认和云端上传范围。

### 19.2 一次日常陪伴

用户发起文字或短语音。系统本地回答，并在需要时展示“我参考了 2 条本地记忆”的可展开说明。若对话中提到稳定偏好或未来计划，系统在结束时提出一张候选记忆卡片；用户可批准、编辑或忽略。

### 19.3 使用云端增强

用户针对某一轮点击云端增强，选择上传模式并确认卡片。系统显示等待状态和供应商别名。云端失败时界面不重复发送，提供“用本地模型回答”与“重试一次”两个明确选项。

### 19.4 创建提醒

用户说“明天上午 9 点提醒我缴费”。系统显示标题、解释后的绝对时间、时区和通知方式。用户确认后才创建提醒；触发后在“今日”页保留完成或稍后提醒的选项。

## 20. 首版交付形态与配置

首版采用本机 Web 应用：启动器启动本地服务并打开 `127.0.0.1` 的浏览器页面；不开发原生桌面壳，不暴露局域网端口。这样可直接复用 Open WebUI 的本地能力，同时将伴侣控制台作为独立、可测试的前端模块。后续如需要托盘常驻或原生窗口，再以桌面壳包装，不改变编排 API 或数据目录。

配置分为以下三类，严禁混用：

| 类别 | 位置 | 可包含内容 | 禁止包含内容 |
|---|---|---|---|
| 应用配置 | 加密数据目录中的版本化 JSON | 界面偏好、模型档案、隐私开关、端口、通知时段 | API 密钥、聊天正文、原始音频。 |
| 密钥引用 | Windows 凭据库 | 云端供应商密钥、备份恢复所需的临时引用 | 导出包中的明文密钥。 |
| 用户数据 | 加密 SQLite、索引和受保护附件目录 | 聊天、记忆、任务、提醒、审计元数据 | 模型权重和第三方缓存。 |

模型档案为只读预设，至少提供 `local-balanced`（Qwen3 1.7B，4-bit，非思考）和 `local-quality`（Qwen3 4B，4-bit，手动启用）。每个档案记录模型 ID、量化级别、最大上下文、最大输出、GPU 层数、空闲卸载分钟数。首版固定每次只运行一个语言模型，禁止用户手工设置并行生成数。

首次安装不自动下载模型、启用麦克风或配置云端密钥。每项都会显示预计下载量、所需磁盘空间、网络目标或系统权限，并由用户确认。

## 21. 本地 API 契约

API 仅监听回环地址，以版本前缀 `/api/v1` 提供服务。所有写操作必须包含启动时签发的本机会话令牌；令牌错误或过期时返回 `401`，不返回数据库细节。

| 接口 | 方法 | 请求/响应摘要 | 规则 |
|---|---|---|---|
| `/conversations` | `POST` | 新建会话，返回 conversation_id | 不写入云端。 |
| `/conversations/{id}/messages` | `POST` | 输入、路由选择、可选云端上传模式；流式返回状态和 token | 云端模式缺少本次确认令牌时返回 `409`。 |
| `/conversations/{id}/memory-candidates` | `GET` | 返回候选记忆及来源 | 仅显示该用户数据。 |
| `/memory-candidates/{id}/approve` | `POST` | 可编辑的最终文本与类别 | 原子地创建已确认记忆并删除候选。 |
| `/memories/{id}` | `PATCH` / `DELETE` | 更新私密隔离、正文或删除 | 删除同时删除索引条目。 |
| `/action-proposals` | `POST` | 解析出的待办/提醒草案 | 不创建任务或提醒。 |
| `/action-proposals/{id}/confirm` | `POST` | 用户确认的字段 | 原子创建任务/提醒，并记录本地审计。 |
| `/cloud/consents` | `POST` | provider_id、上传模式、本轮 request_id | 单次、短时有效；不得复用到其他轮次。 |
| `/export` / `/import` | `POST` | 导出请求或待恢复包 | 导入先进入检查阶段，不立即覆盖数据。 |

流式消息事件统一包含 `request_id` 与以下类型：`queued`、`retrieving_memory`、`awaiting_cloud_consent`、`generating`、`tool_proposal`、`completed`、`degraded`、`failed`。前端只根据这些状态更新界面，不从模型自然语言中推断是否成功创建提醒或完成上传。

## 22. 提示词组装、工具调用与注入防护

每轮模型输入按固定顺序构建：不可修改的安全规则 → 人格风格 → 当前会话的受限摘要 → 已确认且可检索的记忆 → 用户输入。不同来源使用明确边界标记，记忆和摘要均作为“参考资料”而不是可执行指令。

模型不可直接访问网络、文件、数据库、Windows 计划任务或云端密钥。它若认为需要创建待办或提醒，只能返回通过模式校验的结构化“候选操作”。编排层校验名称、绝对时间、时区和重复规则，前端展示确认卡片；确认前不会产生系统效果。

用户消息、记忆文本和云端回复中包含的“忽略规则”“上传全部记录”“调用某工具”等提示都视为普通内容，不能改变路由、上传范围、权限或安全规则。模型输出若无法通过候选操作结构校验，则按普通聊天内容呈现，不执行、不重试。

## 23. 通知与主动互动规则

默认只有用户确认的提醒可以主动弹出 Windows 通知。晨间问候、晚间回顾和未完成待办提示默认关闭；用户可在“关系设定”中分别开启，并设定允许时段。

主动互动必须满足以下条件：

1. 在用户设定的本地时区和允许时段内；
2. 每类主动互动每天最多一次，且总数每天最多两次；
3. 最近 8 小时内没有用户明确关闭或忽略同类提示；
4. 通知正文不暴露私密聊天、记忆或敏感提醒详情；锁屏仅显示通用提示。

通知不能包含施压、占有、内疚诱导或要求立即回复的文案。用户关闭一类主动互动后，系统不以其它类别绕过该偏好。

## 24. 威胁模型与安全边界

| 风险 | 防护 | 不承诺的范围 |
|---|---|---|
| 电脑遗失或磁盘被离线读取 | 数据库和备份加密；密钥由 Windows 凭据库保护；支持应用锁定 | 已解锁且正在运行的电脑无法防御拥有本机控制权的攻击者。 |
| 云端服务看到不该看到的内容 | 默认关闭、单次同意、最小上传、私密隔离过滤、审计元数据 | 用户主动发送的当前消息仍由所选云端供应商处理。 |
| 恶意提示词诱导执行 | 工具能力与模型隔离；结构化候选 + 用户确认 | 模型可能生成不可靠建议，用户仍需自行判断。 |
| 第三方依赖被篡改 | 固定依赖版本、记录来源、校验模型下载哈希、定期更新清单 | 不保证上游项目永远无漏洞。 |
| 误删或损坏数据 | 加密导出、导入检查、删除二次确认、迁移前自动备份 | 用户未导出的历史数据无法保证恢复。 |

“本地优先”表示应用自身不主动上传聊天、记忆和音频；不等同于操作系统、浏览器扩展、恶意软件或用户选择的云端供应商不会处理数据。首次设置页必须用此措辞说明边界。

## 25. 数据迁移、更新与回滚

- 每次数据库结构变更均有单调递增的 schema 版本和可重复执行的迁移记录。
- 迁移前自动创建加密备份；迁移失败则停止启动流程、保留原数据，并提供恢复入口，不在原地猜测修复。
- 升级模型服务、语音模型或前端前，先运行本地健康检查：回环监听、数据库可读、密钥引用可用、提醒调度可写。
- 模型下载使用已知来源、显示许可证与哈希校验结果；下载失败的临时文件不被识别为可用模型。
- 应用版本回滚前先检查数据库兼容性。若旧版本不能读取新 schema，只允许恢复升级前备份，禁止直接降级覆盖。

## 26. 发布门槛与验收清单

在第 8 节验收标准基础上，首版发布前必须全部满足：

- 断网时无任何网络重试循环，聊天、记忆和提醒仍可工作。
- 网络抓包验证：关闭云端时零出站模型请求；开启“仅当前消息”时请求体不含摘要、记忆、音频或 API 密钥。
- 重启后，已确认提醒准确恢复且不会重复弹出；同一提醒触发记录保持幂等。
- 删除一条记忆后，不再被后续检索、会话摘要或向量索引使用。
- 云端确认令牌只能用于创建它的单一 request_id，过期或重放均被拒绝。
- 连续 30 分钟交替文字、语音、提醒操作后，界面仍能继续发起本地聊天，且不出现未处理异常。
- 在锁屏状态下通知不显示完整聊天、记忆或待办正文。

## 27. 实施范围冻结

以下项目明确不属于首版，不能在不修订本设计的情况下加入：多用户、手机同步、局域网访问、自动外发消息、长期持续录音、真人声纹克隆、复杂 3D 数字人、自动执行电脑操作、自动云端故障转移、未经确认的长期记忆写入。

若未来需要其中任一项，应先新增威胁模型、权限界面、数据流和验收标准，再进入实施计划。

## 28. 实施技术栈与代码边界

首版固定以下技术决策，避免在实现阶段重复选型：

| 层 | 采用方案 | 理由与边界 |
|---|---|---|
| 启动器与进程管理 | Windows 启动器脚本 + 本机健康检查 | 仅启动/停止本应用服务，不修改系统代理、防火墙或开机自启。 |
| 伴侣编排后端 | Python 3.12 + FastAPI | 与语音、模型 SDK 生态兼容；以单进程单用户为目标。 |
| 控制台前端 | React + TypeScript 单页应用 | 只通过 `/api/v1` 调用后端；不直接访问 Ollama、数据库或 Windows API。 |
| 持久化 | SQLCipher 保护的 SQLite + 本地向量扩展 | 事务数据和向量索引都在同一受保护目录；不引入独立数据库服务。 |
| 本机密钥封装 | Windows 凭据库 / DPAPI | 保存数据库密钥封装和云端密钥；进程内只在使用期间解封。 |
| LLM 服务 | Ollama | 仅在回环地址访问；由编排层控制模型路由。 |
| 转写与 TTS | faster-whisper + 本地中文 TTS 适配器 | 使用统一 `SpeechService` 接口，使 TTS 引擎可替换。 |
| 测试 | pytest、API 集成测试、Playwright 端到端测试 | 测试使用隔离的临时数据目录和假云端服务。 |

后端模块边界如下：`conversation` 只负责会话与流式响应；`memory` 负责候选、确认、检索和删除；`planning` 负责候选操作和本地提醒；`cloud` 负责同意令牌与供应商调用；`speech` 负责音频生命周期；`security` 负责解锁、密钥和审计；`scheduler` 只负责已确认提醒的触发。模块之间通过明确定义的数据对象调用，不跨模块读写表。

## 29. 本地目录、文件权限与保留期

默认数据根目录为 `%LOCALAPPDATA%\LocalAIMate`；首次运行允许用户更换到本地 NTFS 磁盘上的专用目录，拒绝网络共享、可移动介质和同步盘目录。程序启动时检查该目录仅由当前 Windows 用户读写。

```text
LocalAIMate/
  config/        # 非敏感版本化设置
  data/          # 加密数据库、向量索引、迁移记录
  backups/       # 用户导出的加密备份；不自动上传
  cache/         # 可再生成缓存与模型服务临时文件
  runtime/       # PID、回环会话令牌等，退出即清理
  logs/          # 仅含事件代码与性能指标的轮转日志
```

| 数据类别 | 默认保留期 | 删除/清理规则 |
|---|---|---|
| 聊天原文 | 直到用户删除 | 可按会话、日期、全部清除。 |
| 已确认记忆 | 直到用户删除 | 删除即从正文、索引和摘要来源中移除。 |
| 候选记忆 | 30 天 | 未处理到期自动删除。 |
| 临时会话摘要 | 会话结束后 24 小时 | 不晋升为长期记忆时自动删除。 |
| 原始录音 | 转写成功后立即删除 | 转写失败最多保留 10 分钟供用户重试，之后自动删除。 |
| 语音合成缓存 | 24 小时或退出时 | 取先到者删除；不进入备份。 |
| 性能日志 | 14 天 | 日志不含正文、音频、密钥或完整请求体。 |
| 云端审计元数据 | 90 天 | 只存时间、供应商别名、模式、结果和 request_id。 |

## 30. 字段级数据契约

所有时间存为 UTC 时间戳，同时在业务表中保存创建时本机 IANA 时区标识；界面以当前用户时区显示。所有面向模型或云端的文本先进行长度限制，超限时提示用户缩短，不静默截断。

### 30.1 会话与消息

| 字段 | 类型/限制 | 规则 |
|---|---|---|
| Conversation.id | UUID | 不复用。 |
| Conversation.title | 最多 80 个字符 | 由本地模型生成候选标题或用户编辑；不发送云端。 |
| Conversation.route_default | 枚举 `local` / `ask-cloud-each-turn` | 首次始终为 `local`；即使用户启用每轮询问，也不允许自动云端。 |
| Message.role | `user` / `assistant` / `system-event` | `system-event` 仅表示本地事件，不参与模型上下文。 |
| Message.content | 用户最多 8,000 个中文字符 | 过长消息先拒绝并保留在输入框。 |
| Message.source | `local` / `cloud` / `fallback-local` | 每条 assistant 消息必须有来源。 |
| Message.request_id | UUID | 将流式事件、审计记录和本轮同意关联。 |

### 30.2 记忆与操作候选

| 字段 | 类型/限制 | 规则 |
|---|---|---|
| Memory.category | `profile` / `preference` / `event` / `plan` | 用户可在确认前修改。 |
| Memory.importance | 1–5 | 只影响本地检索排序，不能绕过私密隔离。 |
| Memory.private_local_only | 布尔值 | 为真时不得进入云端摘要、导出预览以外的任何出站内容。 |
| Memory.source_message_ids | UUID 列表 | 必须至少包含一条用户或助手消息，供审核追溯。 |
| ActionProposal.kind | `task` / `reminder` | 没有明确时间时只能生成 task，不能臆造提醒时间。 |
| ActionProposal.absolute_due_at | 可空 UTC 时间 | reminder 必填；显示时同时展示原始自然语言和绝对时间。 |
| ActionProposal.status | `proposed` / `confirmed` / `dismissed` / `expired` | 仅 `confirmed` 可写入任务或提醒表。 |

### 30.3 云端同意与审计

`CloudConsent` 包含 `request_id`、`provider_id`、`upload_mode`、`issued_at`、`expires_at` 和一次性随机 nonce。它有效期为 5 分钟，只能使用一次。`CloudAudit` 仅包含上述标识的哈希、HTTP 结果类别、耗时和模型别名；不得包含上传正文、回复正文、IP 地址、认证头或密钥。

## 31. 关键 API 有效载荷示例

### 31.1 发送消息

```json
POST /api/v1/conversations/{conversation_id}/messages
{
  "content": "明天上午 9 点提醒我缴费",
  "route": "local",
  "cloud_consent_id": null
}
```

后端首先返回 `queued`、`retrieving_memory`、`generating` 事件；若模型提出提醒，则在回答流结束后返回：

```json
{
  "event": "tool_proposal",
  "proposal": {
    "id": "uuid",
    "kind": "reminder",
    "title": "缴费",
    "absolute_due_at": "2026-08-30T01:00:00Z",
    "timezone": "Asia/Shanghai",
    "source_text": "明天上午 9 点提醒我缴费"
  }
}
```

该事件本身不是创建成功通知。前端须调用确认接口，或显示取消选项。

### 31.2 发起云端增强

```json
POST /api/v1/cloud/consents
{
  "request_id": "uuid",
  "provider_id": "configured-provider-alias",
  "upload_mode": "current-message"
}
```

响应只返回一次性 `consent_id`、到期时间和“将上传字段”数组。使用 `cloud-with-summary` 时字段数组必须显式包含 `ephemeral_summary`；前端在显示并获得确认前不得发送下一步模型请求。

### 31.3 确认记忆

```json
POST /api/v1/memory-candidates/{candidate_id}/approve
{
  "content": "用户更偏好在晚上安排第二天的待办。",
  "category": "preference",
  "importance": 3,
  "private_local_only": true
}
```

服务将候选状态和 Memory 创建放在同一事务内。若候选已被处理，返回 `409`，不重复生成记忆。

## 32. 状态机与并发规则

### 32.1 一轮消息状态机

```text
draft → submitted → queued → retrieving_memory
  ├─ local → generating → completed
  ├─ cloud-requested → awaiting_cloud_consent → generating → completed
  │                            └─ cancelled → local 或 cancelled
  └─ failure → degraded(local) 或 failed
```

`cancelled` 不等于删除：已提交的用户消息保留在本地会话中；任何尚未开始的云端调用被取消，且不生成 CloudAudit 的“已发送”记录。已开始云端请求无法撤回第三方已收到的内容，界面须明确显示此限制。

### 32.2 语音状态机

```text
idle → microphone-permission → recording → finalizing → transcribing
  ├─ transcript-ready → draft
  ├─ cancelled → audio-deleted → idle
  └─ error → audio-deleted → idle
```

不支持后台持续监听。录音最长 60 秒；达到限制时自动停止录音、提示用户并继续本地转写。转写期间用户可取消，取消后立刻删除缓冲音频。

### 32.3 并发与幂等性

每个会话同一时刻最多有一个 `submitted` 或 `generating` 消息；第二条消息在界面排队并显示等待状态。不同会话也共享同一个 LLM 生成槽，保证 4GB 显存不会并行超载。所有确认/删除/提醒触发接口接受 `idempotency_key`：相同键的成功操作返回首次结果，避免双击或进程恢复造成重复提醒与重复记忆。

## 33. 系统权限与用户可见授权

| 权限或能力 | 触发时机 | 用户操作 | 拒绝后的行为 |
|---|---|---|---|
| 数据目录读写 | 首次设置 | 选择目录并确认 | 不能创建应用，保留设置页。 |
| Windows 凭据库 | 创建数据库/云端密钥 | 首次解锁或保存密钥时确认 | 可使用无云端、无持久加密数据的演示模式，但不能进入正式使用。 |
| 麦克风 | 第一次按住说话 | Windows 权限弹窗 + 应用说明 | 隐藏录音按钮，文字聊天可用。 |
| Windows 通知 | 第一次确认提醒 | Windows 权限弹窗 | 提醒保留在“今日”页并标记通知未授权。 |
| 网络 | 用户开始模型下载或明确云端增强 | 显示域名/供应商别名与范围 | 本地功能继续可用。 |

不请求相机、位置、通讯录、剪贴板常驻读取、辅助功能、开机自启或管理员权限。若日后引入，必须新增独立设计审查。

## 34. 可执行验收用例

| ID | 前置条件 | 操作 | 预期结果 |
|---|---|---|---|
| E2E-01 | 断网；本地模型可用 | 发送“今天有点累” | 收到标记为本地的中文回复；无网络请求。 |
| E2E-02 | 已确认一条私密记忆 | 选择“仅当前消息”云端增强 | 出站请求不含该记忆、摘要、音频或历史消息。 |
| E2E-03 | 已确认一条普通记忆 | 选择“带上下文增强” | 确认卡片列出临时摘要；请求只含当前消息和该摘要。 |
| E2E-04 | 用户说出明确提醒 | 确认提醒草案后重启应用 | 提醒仅触发一次，且在“今日”页可见。 |
| E2E-05 | 有候选记忆 | 不处理并将系统时间推进 31 天 | 候选被删除，原始聊天仍保留。 |
| E2E-06 | 正在录音 | 点击取消 | 缓冲音频删除，不产生消息或记忆。 |
| E2E-07 | 云端请求已超时 | 选择“用本地模型回答” | 不自动重试云端；本地回复标为 fallback-local。 |
| E2E-08 | 正在生成本地回复 | 连续点击发送两次 | 第二条在同一会话排队；无 GPU OOM、无消息丢失。 |
| E2E-09 | 有已确认记忆 | 删除该记忆后询问相关内容 | 检索来源中不再出现该记忆。 |
| E2E-10 | 锁屏通知开启 | 等待一条确认提醒 | 锁屏只显示通用提醒，不显示待办正文。 |

## 35. 运行诊断与隐私保护的可观测性

控制台设置页提供“系统状态”，只显示：本地模型是否可用、当前模型档案、显存占用区间、语音服务状态、下一条提醒、云端是否配置、最近一次云端调用的结果类别。它不展示聊天正文、记忆正文、录音路径、密钥、完整请求或第三方返回内容。

诊断导出默认关闭。用户主动导出时，生成不含个人文本与密钥的包，包含应用版本、操作系统版本、模型档案名称、错误代码、时间线和资源占用摘要。导出前显示包内容预览，用户可取消。
