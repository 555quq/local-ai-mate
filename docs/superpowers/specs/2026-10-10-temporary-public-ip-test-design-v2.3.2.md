# 露娜临时公网 IP 测试设计 v2.3.2

日期：2026-10-10

状态：设计已确认，待书面规格复核

适用项目：露娜本地 AI 伴侣

基线版本：v2.3.1 OpenSSH 混合私有部署

## 1. 版本目标

本版本为备案完成前的短期联调增加一个隔离入口：

```text
https://49.234.57.214:8443
```

该入口使用受浏览器信任的公网 IP HTTPS 证书、独立临时 Basic Auth 凭据，并在验收成功 72 小时后自动关闭。它只用于少量受邀测试者验证页面、文字对话、麦克风、语音识别和语音朗读，不是绕过 ICP 备案的长期正式发布方案。

正式目标仍是 `https://luna.shipmaster.asia`。备案、DNS、现有域名虚拟主机和 v2.3.1 的 OpenSSH 反向隧道均保持不变。

## 2. 已选择方案

对比过的方案如下：

- 方案 A：公网 IP 的 `8443` 可信 HTTPS。隔离性强，不占用现有 443，支持浏览器麦克风；本版本采用。
- 方案 B：公网 IP 的标准 443。地址更短，但容易与现有域名站点、证书和默认虚拟主机冲突；不采用。
- 方案 C：公网 IP 的高端口 HTTP。部署简单，但不是安全上下文，麦克风通常不可用，且传输不安全；不采用。

测试窗口固定为 72 小时。临时账号与正式 Basic Auth 账号完全分离，不复用生产密码。

## 3. 范围与边界

本版本只增加临时公网边缘入口、证书、临时认证、自动关闭和验收记录。以下内容不在范围内：

- 不把 Ollama、SenseVoiceSmall、GPT-SoVITS、Piper、SQLite、记忆数据或参考音频上传腾讯云；
- 不更换本地模型，不修改人格、界面或语音模型；
- 不新增注册、多用户账户、公开 API 或长期运维面板；
- 不修改 OpenClaw、`www.shipmaster.asia`、管理 SSH 或宝塔面板；
- 不把临时 IP 入口当作 ICP 备案替代方案。

Windows 电脑关机、休眠、断网或 SSH 隧道中断时，静态页面可以加载，但 AI API 应明确显示本地 AI 主机离线。

## 4. 总体架构

```text
受邀测试者
  │ HTTPS :8443 + 临时 Basic Auth
  ▼
49.234.57.214:8443
  │ 独立 luna-temp-edge Nginx 进程
  ├─ /、静态资源 ──► 现有只读 current 发布目录
  └─ /api/* ───────► 127.0.0.1:18765
                              ▲
                              │ 既有 OpenSSH 反向隧道
                              │
                 Windows FastAPI 127.0.0.1:8765
                              │
         Ollama / SenseVoice / GPT-SoVITS / Piper / SQLite
```

临时入口复用服务器现有前端发布目录和 `127.0.0.1:18765` 回环上游，不复制发布包，不开启 18765 或 8765 的公网访问。

## 5. 隔离式 Nginx 边缘

`8443` 使用独立配置目录、PID、日志、临时目录和 systemd 服务 `luna-temp-edge.service`。它复用服务器现有 Nginx 二进制，但不加入主 Nginx 进程的长期虚拟主机集合。这样可以：

- 单独启动、停止和验证临时入口；
- 到期时直接停止独立服务，确保 8443 不再监听；
- 避免临时配置错误影响现有 80/443 站点；
- 不因自动关闭而重启或停止主 Nginx。

独立进程只监听 `0.0.0.0:8443 ssl`，worker 使用现有低权限 Web 用户。静态目录按只读方式访问；临时进程没有修改发布目录、数据库或模型文件的权限。

## 6. HTTPS 与证书

使用支持公网 IP 短期证书的 ACME 客户端版本，为 `49.234.57.214` 签发浏览器可信证书。证书的 Subject Alternative Name 必须包含该 IP，不能用域名证书、自签名证书或忽略证书警告替代。

HTTP-01 验证只在主 Nginx 中临时增加精确匹配 `49.234.57.214` 的 ACME WebRoot 路径：

- 只允许 `/.well-known/acme-challenge/`；
- 其他 IP Host 请求返回 404；
- 不要求 Basic Auth；
- 签发完成后立即移除临时验证配置并通过配置检查后平滑 reload；
- 如果公网 80 验证不可达或证书签发失败，终止部署并回滚，不降级到 HTTP。

公网 IP 短期证书的有效期覆盖 72 小时测试窗口。本次测试不建立长期自动续期；若证书剩余有效期不足 80 小时，则不得启动测试计时。

## 7. 认证与密钥处理

临时入口使用单独随机用户名和至少 128 位随机熵的密码。凭据只在验收完成后向用户显示一次，并保存在服务器 root 可读、临时 Nginx worker 可读取的独立 htpasswd 文件中。

以下内容不得写入 Git、设计文档、实施计划、部署日志或命令历史：

- 临时 Basic Auth 明文密码；
- FastAPI 会话令牌；
- SSH 私钥或完整公钥；
- 聊天内容、录音或合成音频。

临时 Basic Auth 只提供入口访问控制。FastAPI 原有会话令牌校验继续生效，两层认证都必须通过。

## 8. API、Origin 与流式语音

前端和 `/api/*` 位于同一个 IP、协议和端口下，浏览器请求保持同源。临时 Nginx 在转发 API 请求时，把发往后端的 `Origin` 规范化为生产后端已经允许的 `https://luna.shipmaster.asia`。因此不修改、不重启 Windows FastAPI，也不放宽后端允许来源列表。

同源浏览器不依赖跨域响应头读取 API 响应；Origin 规范化只用于通过后端的精确来源检查。Nginx 继续保留必要的 Host、转发地址和协议头，不把 Basic Auth 的 Authorization 头误传成后端会话令牌。

为文字流式回答和语音接口保留：

- `proxy_buffering off`；
- 180 秒代理读写超时；
- `client_max_body_size 9m`；
- 禁止响应缓存；
- 客户端断开时及时终止上游转发。

## 9. TLS 与 HTTP 安全策略

临时入口只接受 TLS 1.2 和 TLS 1.3，并设置适用于临时私有测试的安全响应头。麦克风权限只允许当前站点使用。静态文件、认证失败和 API 错误均不得暴露服务器路径、软件调试信息或凭据。

入口设置温和的连接与请求限速，以降低暴力猜测和误操作风险；限速不能破坏单用户的文字流和语音分段播放。错误密码始终返回 401，API 上游离线返回明确的 502/504，由前端显示“本地 AI 主机暂时离线”。

## 10. 防火墙与端口

腾讯云防火墙仅新增 `8443/TCP` 入站规则。服务器本机防火墙在不改变现有防火墙管理方式的前提下允许 8443；如果 UFW 未启用，本项目不擅自启用 UFW。

端口边界如下：

- 8443：临时 HTTPS 公网入口，72 小时后停止监听；
- 80：仅在签发期间提供精确 IP 的 ACME challenge，现有站点行为不变；
- 443：不被本版本占用或修改；
- 18765：继续只监听服务器 `127.0.0.1`；
- 8765：继续只监听 Windows `127.0.0.1`。

自动关闭以“独立服务停止且 8443 无监听”为安全边界。腾讯云控制台中的 8443 规则无法在不保存云 API 密钥的情况下由服务器定时器删除，因此到期后规则可以暂时保留，但端口没有进程响应；最终收尾时再从腾讯云控制台删除该规则。

## 11. 72 小时自动关闭

只有全部验收通过后才记录 `T0` 并启动 72 小时计时。部署或部分验收时间不计入测试窗口。系统同时记录 UTC 与 Asia/Shanghai 的精确关闭时间。

使用持久化 systemd timer `luna-temp-edge-expiry.timer` 触发幂等清理服务。timer 使用绝对到期时间和 `Persistent=true`，即使服务器在到期时关机，恢复启动后也会立即执行清理。

清理服务按以下顺序执行：

1. 停止并禁用 `luna-temp-edge.service`；
2. 验证 8443 已无监听；
3. 撤销本项目添加的本机防火墙 8443 规则（若存在）；
4. 删除临时 htpasswd、证书副本和独立 Nginx运行目录；
5. 禁用并清理到期 timer；
6. 写入不含秘密的清理结果记录。

清理脚本只操作带有本项目固定名称的文件、服务和防火墙规则，可重复执行。它不删除前端发布目录、域名证书、正式 Basic Auth、SSH 隧道、模型、数据库或生产会话令牌。

## 12. 部署失败与回滚

部署前备份所有会被修改的主 Nginx 文件，并记录校验值。任何阶段失败均遵循“停止暴露优先”：

- ACME 配置或主 Nginx配置检查失败：恢复备份，不 reload 错误配置；
- 证书签发或 SAN 校验失败：不启动 8443；
- 独立 Nginx配置检查失败：不开放云防火墙规则；
- 8443 已被未知进程占用：停止部署，不终止未知进程；
- Basic Auth、会话令牌或 Origin 负向测试失败：立即停止临时入口；
- 文字、语音或隧道失败：入口保持关闭，先修复既有链路；
- 自动关闭 timer 无法持久化：不开始 72 小时测试。

回滚只删除本版本创建的服务、配置、临时凭据、证书和防火墙规则，并恢复被修改文件的原始版本。回滚后必须确认现有域名站点、OpenClaw、宝塔面板和管理 SSH 与部署前一致。

## 13. 验收标准

启用测试窗口前必须全部满足：

1. `https://49.234.57.214:8443` 的证书链受主流浏览器信任，SAN 精确包含 `49.234.57.214`，剩余有效期不少于 80 小时。
2. 未认证访问 `/` 和 `/api/v1/health` 均返回 401；错误临时密码仍返回 401。
3. 正确临时 Basic Auth 与正确 FastAPI 会话令牌下，页面和健康接口成功。
4. 完成一次公网文字输入、流式文字回复和历史记录读取。
5. 浏览器能正常请求麦克风权限，并完成一次语音识别。
6. GPT-SoVITS 流式首段能播放；主语音引擎失败时 Piper 回退能播放。
7. Windows 断开 SSH 隧道后，静态页面仍可加载且界面显示离线；恢复隧道后无需重启临时边缘。
8. 8443 之外不新增公网服务；18765 和 8765 从公网不可达。
9. 现有域名虚拟主机、OpenClaw、宝塔面板和管理 SSH 的前后行为一致。
10. 到期 timer 已启用，精确关闭时间已记录；清理脚本已在替代根目录和模拟服务、防火墙命令的隔离测试中验证作用域与幂等性，未对真实入口提前执行清理。
11. Git、日志、报告和进程参数中不存在密码、会话令牌、私钥、聊天内容或录音。

只有以上检查全部通过，部署才标记为“72 小时临时公网测试已开始”。

## 14. 测试结束后的状态

72 小时后，公网 IP 的 8443 不再监听，临时账号和证书材料被删除，本机模型与数据保持原状。正式域名仍等待 ICP 备案完成；备案完成后继续按 v2.3.1 的域名 HTTPS 方案上线，不复用本次临时凭据。

腾讯云 8443 入站规则由用户或后续收尾步骤从控制台删除。删除规则前后都不影响已经停止的临时服务，也不影响 80/443、SSH 隧道或服务器上的其他站点。

## 15. 资源与风险结论

独立 Nginx 进程的内存和 CPU 开销很低，2 核 2GB、50GB 系统盘足以承载单用户短期测试。AI 推理负载仍在 Windows 电脑上，服务器性能不是主要瓶颈。

主要风险仍是 Windows 本机可用性、腾讯云对未备案公网入口的网络策略，以及公网 IP 短期证书签发链路。设计通过短期窗口、独立凭据、可信 HTTPS、隔离进程、失败即关闭和持久化到期清理降低风险，但不改变备案要求。
