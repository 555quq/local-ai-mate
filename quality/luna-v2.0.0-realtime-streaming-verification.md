# 露娜实时流式语音 v2.0.0 验证报告

验证日期：2026-10-09  
结论：通过；默认选择混合 CUDA 工作进程，保留 CPU GPT-SoVITS 与 Piper 自动回退。

## 交付范围

- 长期驻留、版本化 NDJSON 标准输入输出协议的 GPT-SoVITS 工作进程。
- FastAPI `POST /api/v1/tts/stream` 流式接口。
- React 分段解码、有序播放、取消和对象 URL 清理。
- `CUDA → CPU GPT-SoVITS → Piper` 的首段前回退链。
- 8 项、32 MiB 上限的进程内完成流缓存。
- CUDA 与 CPU 独立片段超时；中文协议强制 UTF-8。

## 隐私与故障边界

- 工作进程只通过本机 stdio 通信，不开放额外端口。
- 音频片段与缓存只在内存中存在，不写入聊天数据库。
- 健康接口只暴露经过清理的引擎、设备和状态，不返回路径、正文或音频。
- CUDA 或 CPU 只有在尚未输出首段时才能降级；输出首段后失败会终止本轮，避免中途更换音色。
- 浏览器停止、替换播放或页面卸载会中止请求、停止音频并释放对象 URL。

## 已知限制

- 后端首次启动需要约 31 秒加载模型。
- 进程启动后的第一次朗读需要约 5–7 秒建立参考提示缓存。
- 4 GiB 显存机器不适合把 BERT、语义模型和声码器全部同时放在 CUDA；当前混合布局是验收通过的默认值。
- 当前 SQLite 仍是开发期明文数据库，不应存放真实敏感对话。
