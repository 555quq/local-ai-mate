## 自动化质量门槛

- [ ] `python -m pytest .\quality\tests -m api -q` 在隔离后端上运行；无失败、无跳过。
- [ ] `python -m pytest .\quality\tests -m privacy -q` 在 `APP_TEST_MODE=1` 下运行；无失败、无跳过。
- [ ] 测试报告不含聊天正文、音频、密钥、令牌、完整请求/响应或用户路径。
- [ ] 30 分钟本地聊天基线无服务退出或显存耗尽；90% 普通消息在 5 秒内开始响应。

## 本地优先与云端边界

- [ ] 新安装/新测试数据目录中，云端增强和主动互动均为关闭；自动朗读默认开启且可由用户立即关闭。
- [ ] 断网后可新建会话、发送中文文字消息、检索已确认记忆、创建本地提醒。
- [ ] 关闭云端时，网络监控未发现模型、遥测或更新出站请求。
- [ ] “仅当前消息”预览明确显示供应商、模型、字段及字符数；假供应商只收到当前消息。
- [ ] “带上下文增强”预览只新增临时摘要；私密隔离记忆、完整历史、音频、待办和 API 密钥均未发送。
- [ ] 修改消息、改变供应商/模式、或等待超过 5 分钟后，旧云端同意失效。
- [ ] 云端超时后不会自动重试或扩展上传范围；用户可选用本地模型回答。
- [ ] 可选 Ollama 只接受 `127.0.0.1` 端点；不可用时提示本地降级，不得自动改发云端。
- [ ] Piper 只在 CPU 上运行；中文回复可生成有效 WAV，自动朗读、单条重播/停止和全局关闭均可用。
- [ ] TTS 空白、超长、忙碌和不可用错误不会改变文字消息，也不会创建临时 WAV 文件或发起云端请求。
- [ ] 设置页的“暂停候选记忆”和“暂停记忆检索”重启后保持，并分别阻止候选生成和检索。

## 数据与提醒

- [ ] 候选记忆只有明确批准后才能进入检索；拒绝或过期候选不进入长期记忆。
- [ ] 删除已确认记忆后，向量检索、临时摘要和来源引用均不再可用。
- [ ] 明确提醒经确认后写入；重启后只触发一次，冲突不自动覆盖。
- [ ] 导出包可在临时目录校验、恢复；篡改清单或密码错误不会改写现有数据。
- [ ] 清空全部数据会明确提示离线备份仍需用户手动删除。
- [ ] 导出接口/文件不包含会话令牌、云端 API 密钥、授权头、密码或任何秘密字段。
- [ ] 清空本地数据必须要求勾选确认并输入“清空本地数据”；成功后对话、消息、候选、记忆、待办和提醒均不可再读取，隐私开关恢复默认值。

## 本机安全与降级

- [ ] 服务只监听 `127.0.0.1`；随机端口、Origin 校验和短期会话令牌有效。
- [ ] 未携带或携带过期令牌的写操作返回安全的 `401`，不泄露堆栈或路径。
- [ ] 本地模型、语音或数据库失败时保留用户草稿，不会自动发送云端。
- [ ] 锁定或退出后，短期令牌、临时摘要和未完成音频缓冲被清理。
- [ ] 锁屏通知不显示提醒正文；关闭自动朗读会立即停止当前音频，刷新页面后不恢复旧音频 Blob。
